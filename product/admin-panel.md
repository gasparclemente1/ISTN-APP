# Admin Panel Requirements

Protected admin area.

## Central team
- Manage featured content.
- Manage teachings and metadata.
- Manage live events and current Zoom URL.
- Manage global announcements.
- Manage countries/regions/churches.
- Verify contacts and schedules.
- Manage notification campaigns.
- Review AI-generated summaries/tags before publication.

## Local congregation editor
Can edit only assigned congregation data:
- address
- service schedules
- responsible leader
- phone/WhatsApp
- local announcements
- verification request

## Auditability
Every important change should record:
- who changed it
- when
- previous value
- new value

No production schedule/contact should depend on source code changes.
